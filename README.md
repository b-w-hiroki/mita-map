# 三田・田町マップ

三田・田町エリアの新職場周辺ガイドとして、飲食店や買い出し先を地図と一覧で探せる単一 HTML ファイルの Web アプリです（`index.html` のタイトル／ヘッダー表記「三田・田町マップ」「新職場周辺ガイド」に基づく）。

## できること

- **モード切替**: 「グルメ」と「買い出し」
  - グルメ側のカテゴリ例: ランチ、ディナー、居酒屋、バー、カフェ
  - 買い出し側のカテゴリ例: コンビニ、スーパー、ドラッグストア
- **地図＋一覧表示**: 地図上のマーカーとサイドバーの店舗カード／詳細パネル連動。価格、評価、徒歩目安などの情報を表示
- **絞り込み**: カテゴリと、拠点からの半径（すべて／300m／500m／800m／1km）
- **お気に入り・訪問履歴**: お気に入り登録と、訪問日・評価・食べたもの・メモの記録
- **拠点設定**: 拠点の検索・設定に対応。ライト／ダークのテーマ切替あり

## 開き方

`index.html` をブラウザで開いてください。ビルドは不要です。

## テスト

セキュリティ回帰テストがあります。

- `security.test.js` — Node.js のテストランナーで実行するテスト（訪問履歴や検索結果の文字列の literal 表示など）
- `browser.test.js` — Playwright（Chromium）で実際にブラウザ上で確認するテスト

CI: `.github/workflows/security-tests.yml` が `push` / `pull_request` で Node.js 22 を使って両テストを実行します。

ローカル実行の例（CI の手順に基づく）:

```sh
node --test security.test.js
npm install --no-save playwright
npx playwright install --with-deps chromium
node browser.test.js
```

## 掲載情報と位置情報の限界

- 店舗データの出典・最終確認日は現状未確認です。確認していない日付を更新日として表示しません。営業時間・価格・営業状況は店舗公式情報を来店前に確認してください。詳細画面から公開 GitHub Issue へ訂正を提案できます。個人情報は記載しないでください。
- 徒歩時間は拠点からの直線距離÷80m/分の目安で、道路・信号を含む経路所要時間ではありません。
- 位置情報を拒否しても住所・駅名検索を利用できます。取得中の連打を防ぎ、閉じた後の遅延応答で拠点を変えません。取得タイムアウトは10秒です。
- 店舗ごとの一次資料照合と実機位置情報検証は未実施です。
